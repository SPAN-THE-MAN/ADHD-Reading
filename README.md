# ADHD-Reading/Speed-reader
An OSU portfolio project that utilizes several microservices to facilitate an API for purposes of reading aid and focus.

How to use:
1. Start all microservices
   File_Upload_Service.py
   OCR_Text_Scrape_Service.py
   Search_Feature_Service.py
   Text_Chunking_Service.py
2. Start advancedAPI.py
3. Follow on screen API instructions.
